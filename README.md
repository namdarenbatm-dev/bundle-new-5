# Smart Bundle — بسته شاپرکی توسن تکنو (PWA)

این نسخه بر اساس مدل اقتصادی فریز‌شده‌ی **بسته شاپرکی** آماده شده است. بسته شتابی از موتور باندلینگ حذف شده است.

## محتویات
- `index.html` — داشبورد مدیریتی، پیش‌نمایش کارگزار و کنترل اقتصادی
- `manifest.webmanifest` — تنظیمات نصب PWA
- `sw.js` — سرویس‌ورکر و کش آفلاین
- `assets/fonts/Yekan.ttf` — فونت یکان
- `assets/tosan-techno-logo.png` — لوگوی توسن تکنو
- `assets/icon-192.png` و `assets/icon-512.png` — آیکن‌های PWA

## منطق اقتصادی فریز‌شده

- محصول هدف: کارتخوان؛ مدل باندلینگ فقط برای بسته شاپرکی محاسبه می‌شود.
- شرط ترکیب: تعداد کارتخوان باید **بیشتر از** تعداد کشلس باشد.
- بودجه قابل تخصیص به تخفیف کارتخوان: `تعداد کشلس × (قیمت فروش کشلس − بهای تمام‌شده کشلس − سود هدف هر کشلس) − تعداد کارتخوان × بودجه بازاریابی هر کارتخوان`.
- بودجه بازاریابی هر کارتخوان از همان حاشیه سود کشلس تأمین و هنگام محاسبه سفارش کسر می‌شود؛ منبع مالی جداگانه‌ای فرض نمی‌شود.
- تخفیف هر کارتخوان از بودجه باقی‌مانده محاسبه می‌شود، اما از تخفیف لازم برای رسیدن به قیمت هدف بیشتر نمی‌شود؛ قیمت بسته پایین‌تر از قیمت هدف نمی‌رود.
- اگر بودجه منفی باشد یا ترکیب با شرط بسته شاپرکی سازگار نباشد، سفارش غیرمجاز است. اگر بودجه مثبت اما ناکافی باشد، قیمت قابل‌دستیابی و هشدار نمایش داده می‌شود.
- بودجه استفاده‌نشده خودکار به تخفیف اضافی تبدیل نمی‌شود.

## مقادیر نمونه
- قیمت پایه کارتخوان: ۲۰ میلیون تومان
- قیمت هدف کارتخوان: ۱۵ میلیون تومان
- بهای تمام‌شده کشلس: ۲۵ میلیون تومان
- قیمت فروش کشلس: ۴۰ میلیون تومان
- سود هدف هر کشلس: ۲ میلیون تومان
- بودجه بازاریابی هر کارتخوان: ۲ میلیون تومان
- ترکیب نمونه: ۵ کارتخوان و ۲ کشلس

با این مقادیر، بودجه تخفیف قابل تخصیص `۲ × (۴۰ − ۲۵ − ۲) − ۵ × ۲ = ۱۶` میلیون تومان است. تخفیف هر کارتخوان ۳٫۲ میلیون تومان و قیمت نهایی آن ۱۶٫۸ میلیون تومان خواهد بود. بودجه بازاریابی ۱۰ میلیون تومان به‌صورت مجزا از همان حاشیه سود تأمین شده است.

## انتشار روی GitHub Pages
1. فایل ZIP را استخراج کنید.
2. تمام فایل‌ها و پوشه‌های داخل ZIP را در ریشه مخزن GitHub Pages آپلود کنید.
3. Commit کنید و در **Settings → Pages** انتشار از شاخه و پوشه ریشه (`/`) را فعال کنید.
4. سایت را از طریق HTTPS باز کنید. برای نصب PWA، اجرای مستقیم با `file://` کافی نیست.

## خروجی‌ها
- دکمه «خروجی اکسل» فایل CSV سازگار با Excel تولید می‌کند.
- دکمه «خروجی PDF» پنجره چاپ مرورگر را باز می‌کند تا PDF ذخیره شود.
- صفحه آغازین ۵ ثانیه نمایش داده می‌شود و اعتبار طراح «مهدی نامدار» حفظ شده است.
